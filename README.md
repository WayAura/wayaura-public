# Аура — голосовой помощник для автомобиля

Аура — автомобильный голосовой ассистент для Android и iPhone. Телефон с приложением подключается к
OBD-адаптеру машины и к магнитоле; Аура объясняет понятным языком данные автомобиля, отвечает на вопросы,
ищет информацию и помнит важное между поездками.

**Что Аура будет уметь в первой версии**
- просыпаться по слову «Аура» и останавливаться по стоп-слову;
- проверять доступные данные машины перед поездкой и честно говорить, что проверено, а что нет;
- объяснять показатели и коды ошибок, сообщать о важных событиях в пути;
- отвечать на общие вопросы, рассказывать погоду, искать сведения в интернете с указанием источников;
- помнить машину, важные факты и прошлые разговоры — по вашему желанию и под вашим контролем.

**Чего Аура не делает:** не читает мессенджеры и не отправляет сообщения; не сбрасывает ошибки и не
управляет блоками автомобиля — диагностика только в режиме чтения; не выдумывает показатели.
