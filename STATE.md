# Состояние (2026-10-06)

Основа проекта (G0) готова. Голосовая часть проверки рисков (G1) пройдена: Аура говорит служебные фразы
одинаково каждый раз, запоминает и забывает сведения по голосовой просьбе, ищет в интернете с указанием
источников. Проверка работы телефона в фоне, со звуком машины и с адаптером продолжается.

Идёт этап G2 — первый сквозной голосовой диалог на тестовых данных:
- на тестовом сервере работает весь путь: приветствие, проверка, слово «Аура», ответ по показателю машины,
  остановка по стоп-слову;
- короткие команды и цепочки просьб («… и потом …»);
- необратимые действия (удалить историю, «забудь всё», завершить поездку) Аура выполняет только после голосового
  переспроса;
- слово «Аура» и стоп-слова распознаются прямо на телефоне, без интернета и без отправки звука, — первая
  версия для Android работает на тестовом телефоне.

Дальше: та же часть для iPhone, приложение и проверка всего пути на обеих системах.
