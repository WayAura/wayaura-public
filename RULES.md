# Правила публикации (публичная часть)

- Сюда попадает только то, что можно показать людям: описание продукта, публичная дорожная карта, общие
  принципы.
- Никаких ключей, адресов, внутренних деталей архитектуры, договоров, планов и решений, которые команда не
  решила публиковать; никаких персональных данных.
- Изменения — через pull request, который одобряет владелец проекта.
- Полные правила работы команды ведутся в закрытом репозитории.
